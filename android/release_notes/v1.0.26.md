# EpiMediaHub Android 1.0.26

- Intro-Erkennung: Die App berechnet beim normalen Abspielen einer Folge kleine Audio-Fingerprints aus den ersten zwölf Minuten und überträgt nur diese Fingerprints an den gekoppelten Server. Es wird keine zweite Anbieter-Verbindung geöffnet. PCM bleibt auf dem Gerät und wird nur kurz im Arbeitsspeicher gepuffert.
- Die Berechnung läuft außerhalb des Wiedergabe-Threads. Bei Sprüngen und Tonspurwechseln beginnt ein neuer zusammenhängender Abschnitt. Vollständig erfasste Introfenster ersparen dem Analyseworker nach der Laufzeitprüfung einen erneuten Audioabruf.
- Der passende Server verarbeitet App-Fingerprints auch während einer Wiedergabe. Vier unabhängige Folgen können mit dem bestehenden Staffelvergleich automatische Introzeiten liefern. Unklare Treffer bleiben zur Prüfung; eigene Korrekturen haben Vorrang. Das setzt das separate Fingerprint-Serverupdate voraus.
- Radio: größere TV-Tastatur, eigene Zahlenreihe 0–9, alphabetische Buchstabenreihen sowie größere Tasten für Leerzeichen, Zurücklöschen und Löschen. Eine leere Suche lässt sich weiterhin mit „Übernehmen“ schließen.

Signierte Updates für ARM64, ARMv7 und Universal. Serientimer, Playlist-Reihenfolge, Tagesbudget und vorhandene Zeitmarken bleiben erhalten. Der echte Durchsatz und die Bild-/Tonqualität auf dem jeweiligen TV-Stick müssen im laufenden Betrieb beobachtet werden.
