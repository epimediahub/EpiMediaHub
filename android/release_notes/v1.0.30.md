# EpiMediaHub Android 1.0.30

- SmartTube Kids lässt sich ohne eingerichtete Eltern-PIN direkt öffnen und verlassen. Es wird keine PIN-Einrichtung mehr erzwungen.
- Ist bereits eine Eltern-PIN eingerichtet, bleibt das Verlassen von Kids damit geschützt. Das gilt auch für die Zurück-Taste und nach einem App-Neustart.
- Ohne Eltern-PIN heißt die Schaltfläche „Zurück“; mit PIN weiterhin „Eltern · PIN“.

Die Skins bleiben in diesem Update unverändert. Die Katalog- und Fernbedienungs-Korrekturen aus 1.0.29 sind enthalten.
