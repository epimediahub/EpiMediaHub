# EpiMediaHub Android 1.0.46 — Speedtest HTTP 403 Fehlerbehebung

Offizielles Update der bestehenden EpiMediaHub-App (kein separates Beta-Paket).

- Bei **HTTP 403/429** auf dem Cloudflare-Downloadtest wird ausschließlich die **Test-Gegenstelle** auf die offizielle HTTPS-Datei **Hetzner HEL1, Helsinki** gewechselt. Die aktivierte Finnland-VPN wird dabei **nicht** abgeschaltet.
- Reale, begrenzte Downloads: Hetzner-Testdatei wird nur bis zur benötigten Größe gelesen. Die übertragenen Bytes werden gemessen und niemals als ausgedachte Geschwindigkeit angezeigt.
- Vergleich mit **1 / 2 / 4 gleichzeitigen Verbindungen** auf derselben Download-Gegenstelle; Tacho bleibt bis 1 Gbit/s skaliert.
- Falls Cloudflare den Upload ebenfalls sperrt, zeigt die App **„Upload nicht verfügbar“** statt 0 Mbit/s.
- Fehlerstatus von HTTP-Testserver und tatsächlichem VPN-Routing werden getrennt behandelt; bestehender VPN-Schutz, IP-Checks und Netzbindung bleiben unverändert.
- Einzelne Cloudflare-Anfragen nutzen nur dokumentierte Parameter und maximal 64 MiB.
- Kein Downgrade und keine Neuaktivierung: Paketname `de.epimediahub.app`, App-Signatur und Nutzerdaten bleiben erhalten.

**Hinweis:** 403 kann von Serverregeln und der verwendeten öffentlichen VPN-Adresse abhängen. Die Nutzung einer Alternativ-Gegenstelle verbessert die Messbarkeit, nicht automatisch die reale Internetgeschwindigkeit. Downloadwerte von verschiedenen Gegenstellen sind nicht direkt gleichzusetzen. Die App wird weiterhin auf Fire TV hardwareseitig geprüft.
